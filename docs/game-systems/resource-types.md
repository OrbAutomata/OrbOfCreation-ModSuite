# Resource types and keywords

Every resource carries one or more type keywords, and effects target those keywords rather than
individual resources. An effect that boosts "the rate of all Mental resources" boosts every Mental
resource you own, present and future.

The full type list:

> Blooming, Building, Celestial, Elemental, Energetic, Essence, Hexed, Liquid, Magic, Mental, Metal,
> Natural, Parchment, Spacial, Advancement, All Capped, All, Influential, Progression, Spiritual,
> Tempered.

Most are flavour categories. Four are structural targeting groups: `All` (everything — Achievement
Strength targets it), `All Capped`, `Advancement` and `Progression`.

## Membership is many-to-many

Most resources carry two keywords, so a single keyword-targeted effect usually touches more than you
expect. Early in a run a broad-sounding effect is often degenerate: "+6.45 % base Elemental resource
rate" is a mana-rate multiplier while mana is your only Elemental resource.

Observed memberships — one save's visible set, not the authored roster:

| Resource | Types |
|---|---|
| Mana | Magic, Elemental |
| Knowledge | Magic, Mental |
| Psi | Mental, Energetic |
| Thaumaturgy | Spacial |

Observed members of the Mental type: Control, Knowledge, Psi, Skill, Cognitive Disc.

Attribute names and Attribute categories are targetable keywords too, so the same grammar reaches
beyond resources.

## Type levels

A resource type can be levelled with **Materials Upgrade** points (from Alchemy and Mystic tab
levels; see [advancement-currencies.md](advancement-currencies.md)). Each type's level carries its
own effects, often a point cap among them. Observed first-level prices were 3 points on every type,
with these effects:

| Type | Per level |
|---|---|
| Natural | +3 Biotic Capacity, +1 Ability Advancement |
| Essence | +1 Orb Advancement, ×1.12 Transmute and Refinement power |
| Parchment | +1 Cognitive Advancement, −0.8 % Book cost scaling |
