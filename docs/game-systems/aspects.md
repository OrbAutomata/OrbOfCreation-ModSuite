# Aspects

**World > Aspects** is a set of **three pedestal slots** holding placed aspects, and it is how the
game's major late systems arrive: Aspect: Workshop, Aspect: Alchemy Lab and Aspect: Rituals each
unlock their system through one of these world slots, granted by its upgrade.

Each of Gather Space, Gather Space II and Gather Space III adds one pedestal. The Aspects subtab,
and with it every aspect upgrade, stays hidden until the first one is bought, even though Aspect:
Workshop and Aspect: Alchemy Lab have no prerequisites of their own.

New aspects arrive through **discovery events**. There is no standing "aspect offers" page — the
offer appears when the game presents it rather than somewhere you can go and check.

Empty capacity slots elsewhere in the game are real and intentional: the game preserves them in
saves, so an empty row is never evidence of a lost item.
