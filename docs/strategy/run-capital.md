# Run capital

## Distribute Time Advancements

Per-level costs rise inside a rune while returns diminish, so **equalize marginal returns across all
the runes the run gives you** — roughly seven to ten. Breadth beats depth.

- **The first level of every rune is free, and an unlevelled rune is inert.** Take the free level on
  every rune you pick, without exception.
- **Rune mastery is the compounding part**: each mastery point is +1 starting Time Advancement next
  run. Take every rune to at least its first mastery level (about rune Lv 4: 6 TA, 3 on a Superior
  rune), and stop deeper levels at a mastery boundary, not a round number.
- **Only Persistent-tagged runes are cross-run capital.** Their granted levels keep applying even
  though the rune itself is cleared at reset, and repicking is only needed to buy *more* levels.
  Non-persistent runes are run-local power, but a run lasts many hours and late costs grow fastest:
  value a run-local rune at the end of the run, where scaling effects beat upfront ones.
- **Runes are few, so set up each roll before paying it.** Rarity, the number of options and the
  reroll budget are all fixed or spent at roll time. Level Discovery Rarity first, and hold an
  optional roll while a near unlock would add an option.
- **Time Advancements are refunded at every reset**, so there is no spend-timing risk at all. The
  only thing to get right is the split.

## Pick the challenge posture, then honour it

Challenges change the rules of a run, and they modify *requirements* rather than only numbers, so a
node's gate can be several levels cheaper than its base text says. An easy set makes it a chill run,
which shifts every fork toward permanent cross-run bonuses over run-local power; a hard set inverts
that. The posture is the tie-breaker on every pool pick the run will present, and deciding it once
beats re-arguing it a dozen times under time pressure.

## Advancements are run-finite

The advancement points a run mints are bounded, and only a new run resets the curves. **You will
never research everything**, so every allocation is a choice against everything else you could have
had.

- **Spend them on engines you are actually running.** An advancement buffing a discipline you have
  not unlocked is dead capital for this run, however large the numbers look.
- Orb levels double as unlock keys with hidden thresholds — apply the one-way-door rule from
  [decision-rules.md](decision-rules.md) and hold until you can read the gates.

## The run's real output is capital

The compounding chain is **spell level → more output and more XP per cast → mastery faster → more
Time Advancements next run.** One purchase pays three dividends across three horizons.

**When two candidates tie on time-to-milestone, take the one that also feeds a cross-run track** —
the milestones reset at the next run; the capital does not.

- **Count casts, not stock, when planning through a mastery gate.** Mastery XP and the spell-type
  tracks fill only by casting, so a mastery gate is cleared by scheduling the activity, never by
  saving. The global casting level also ticks passively, so idle time is not wholly wasted.
- **Meta-velocity is purchasable.** Attributes that raise spell mastery rate spend run-local currency
  to buy cross-run capital velocity — an unusually good trade in a run you intend to reset from
  anyway.
